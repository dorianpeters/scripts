# Scripts
This repository contains scripts for setting up development environments. Both scripts are for Debian-based systems and require sudo privileges. Both install git, curl, unzip, nodejs and pnpm (using corepack), and configure git with the user's name and email. It also generates an SSH key for the user and outputs the public key to the console.

## js_setup.sh
This script installs nodejs using the NodeSource repository.

## odin_setup.sh
This script installs nodejs using the fnm version manager.
